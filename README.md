# Enchanted Grinding

## About
The mod allows you to move enchantments from equipment onto books using a grindstone.

## Inspiration
This mod is inspired by [Grind Enchantments](https://modrinth.com/mod/grind-enchantments), it essentially performs the same function but features simpler configuration and, in some cases, better compatibility.<br>
Not a single line of code was taken from Grind Enchantments.
